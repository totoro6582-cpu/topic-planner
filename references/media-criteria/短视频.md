# 短视频（抖音 / 视频号 / B 站）· 选题过三关具体指标

## 数据源

- **热点与选题**：抖音创作者中心热点榜、巨量算数、视频号热点、B 站热搜、百度指数
- **同类内容**：同类账号/同类选题的完播率、点赞、评论、转发数据（能查到的公开数据，如账号主页播放量、评论区讨论热度）
- **平台差异**：注意抖音偏公域算法推荐、强平台热梗；视频号权重更依赖好友社交关系链（据公开分析，好友点赞/评论等"社交推荐"在推荐权重中占比显著高于纯内容质量的"热门推荐"）；B 站偏深度、互动弹幕文化强。选平台时要对应判断，不能三个平台用同一套逻辑

## 选题过三关在短视频场景的具体化

**第一关 · 需求关**

1. **话题势能**：这个选题有没有已经成为平台热梗、挑战或反复被创作的母题？
2. **刚需强度**：观众的痛点/好奇心是不是真实存在，而不是创作者自己觉得"这个很有意思"？
3. **互动/传播理由**（不是"即时驱动力"——短视频类平台看的是受众愿不愿意点赞、评论、转发）：受众看完之后，有没有清晰的理由去点赞、评论、转发甚至 @ 朋友，而不是划走就算了？开头 hook（0-3 秒的冲突/悬念/反常识/强视觉）决定能不能留人看完，但能不能留下互动动作才是决定内容能不能被算法/社交关系链进一步分发的关键。
   - **抖音/B 站**：完播率、点赞、评论、转发是公域算法打分的核心信号，权重依次递增（转发权重通常高于评论、评论高于点赞）。
   - **视频号**：分发本质是熟人社交裂变——好友点赞会让内容在好友的"朋友在看"里曝光，转发会覆盖更大范围的好友和延伸社交圈；判断这一项时要问"我的目标受众看完，会不会有冲动转发给具体的某个朋友/亲人看"，而不只是"会不会看完"。

**第二关 · 竞争关**

4. **竞争位势**：同类选题红海程度如何，有没有差异化角度（人设、视角、信息差）不被大账号淹没？
5. **载体适配度**：为什么这个内容适合做视频（强视觉、强情绪、强节奏、需要演示/画面才能讲清楚），而不是一篇图文或一条笔记就能讲完？

**第三关 · 回报关**（加速器，不是及格线）

6. **触达潜力**：账号现有粉丝画像和目标观众重合度；有没有素材/画面/出镜资源支撑这个选题落地？
7. **复利潜力**：这个选题能不能延展成系列内容，还是拍完就用尽了，对账号人设有没有长期沉淀价值？

## 产出物格式（模式一步骤 4-5）

- 建议标题/封面文案：1-2 个方案，标注封面文字和标题的钩子类型（悬念/冲突/数字/反常识）
- 结构框架：分镜/脚本大纲——开头 hook（0-3 秒）→ 中段信息展开（分 2-4 个小节点）→ 结尾（结论/反转/引导关注转发）

## 常见风险

- 内容层面：素材/画面能否支撑脚本，是否需要额外拍摄或素材采购
- 市场层面：选题是否已经被大量创作，红海程度评估
- 审读/合规层面：涉及医疗、金融、未成年人等内容需标注平台规则风险，提醒人工复核
