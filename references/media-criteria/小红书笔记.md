# 小红书笔记 · 选题过三关具体指标

## 数据源

- **搜索需求**：小红书搜索下拉词、相关关键词笔记数量和近期新增趋势
- **同类笔记**：同类选题笔记的点赞/收藏/评论比例（收藏比高通常说明"实用/攻略"类需求强）
- **蒲公英指数**：如可查，参考同类博主/关键词的商业热度数据作为参考

## 选题过三关在小红书笔记场景的具体化

**第一关 · 需求关**

1. **话题势能**：这个话题是不是已经在小红书形成了固定的内容类型（种草/避坑/攻略/测评），有天然的搜索和浏览习惯？
2. **刚需强度**：是不是命中了"避坑""省钱""怎么选""怎么做"这类强决策场景的刚需强度？
3. **即时驱动力（点开/收藏/点赞）**：封面和标题能不能让人一眼看出"这条能帮我解决具体问题"？内容是不是"有用到想收藏"的程度，而不只是"看着舒服"？

**第二关 · 竞争关**

4. **竞争位势**：同类关键词下已经有多少篇笔记，本篇的差异化角度（更细分人群、更新数据、更强对比）是什么？
5. **载体适配度**：为什么这个内容适合做笔记（强场景化、强实用清单、强图文对比），而不是拍成视频或写成长文更合适？

**第三关 · 回报关**（加速器，不是及格线）

6. **触达潜力**：账号人设/粉丝画像和目标受众重合度；有没有实拍图片/对比素材支撑内容可信度？
7. **复利潜力**：这篇笔记能不能长期通过搜索获得流量（长尾种草），还是只能蹭一次热点后就沉底？

## 产出物格式（模式一步骤 4-5）

- 建议标题：含关键词布局的标题方案（前置搜索关键词 + 情绪/数字钩子），2-3 个
- 结构框架：封面文案（一句话结论）→ 正文结构（痛点开场 → 干货罗列/对比清单 → 结尾引导收藏或互动）→ 标签建议（3-5 个搜索标签）

## 常见风险

- 内容层面：干货/清单是否有真实测评或数据支撑，避免"标题党正文空"
- 市场层面：关键词竞争度是否过高，是否需要找更细分的长尾角度
- 审读/合规层面：涉及医美、金融理财、保健品等内容需标注平台合规风险，提醒人工复核
